Electrical Control Circuits

01

Motor Start / Stop

Basic motor control circuit using contactor, push buttons and overload relay.

02

Two-Station Start / Stop

Motor control circuit that allows the motor to be started and stopped from two locations.

03

Motor Interlocking Control

Motor control circuit that prevents two motors from running at the same time.

04

Motor Sequential Interlocking

Motor 2 can only run when Motor 1 is running, while Motor 1 can only stop when Motor 2 is stopped.

05

Alternating Motor Control

Two-motor control circuit where starting one motor automatically stops the other.

Timer-Based Control Circuits "6-Circuits"

Practical timer-based circuits for motor control, sequencing, and timed operation.

Forward / Reverse

Motor direction control using electrical interlocking.

Star-Delta Starter

Three-phase motor starting circuit using Star-Delta configuration.

15

Alternate Operation Control

Control circuit that prevents either load from operating twice consecutively, requiring the other load to operate before it can run again.

16

Single Push Button Start-Stop Control

Starts and stops a motor using a single push button, toggling its operating state with each press.

17 & 18

Automatic Transfer Switch (ATS)

Automatic transfer switching circuit that transfers the load between the main power supply and the backup generator.
